Lección 1: JavaScript para alguien que sabe Python

No tienes que instalar nada. Abre Chrome, presiona F12, ve a la pestaña Console y escribe ahí. Es como el intérprete de Python.

Python	JavaScript
lista = [1, 2, 3]	const lista = [1, 2, 3];
d = {"sede": "Norte", "hombres": 42}	const d = { sede: "Norte", hombres: 42 };
d["sede"]	d.sede
print(x)	console.log(x)
f"Sede {s}"	`Sede ${s}` (comillas invertidas)
for x in lista:	for (const x of lista) { ... }
[x * 2 for x in lista]	lista.map(x => x * 2)
[x for x in lista if x > 1]	lista.filter(x => x > 1)
sum(lista)	lista.reduce((acum, x) => acum + x, 0)
None	null (y también existe undefined)
==	=== (usa siempre el de tres)

La misma idea en Polars:

js
// Polars: df.filter(pl.col("sede") == "Norte")
filas.filter(f => f.sede === "Norte")

// Polars: df.with_columns((pl.col("a") / pl.col("b")).alias("pct"))
filas.map(f => ({ ...f, pct: f.a / f.b }))

const es para algo que no vas a reasignar y let para algo que sí. Nunca uses var, que es la forma vieja.
